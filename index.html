Objetivo del servicio

Una metodología clara para cambiar tu web.

La presente propuesta tiene como objetivo establecer una metodología clara para realizar modificaciones, actualizaciones y mejoras sobre el sitio web de VALCA.

El sitio se encuentra desarrollado mediante código, por lo que las tareas pueden implicar modificaciones sobre contenido, HTML, CSS, JavaScript, componentes, estilos, comportamiento responsive y estructuras existentes.

Para simplificar la contratación y evitar presupuestar cada pequeño cambio por separado, las actualizaciones se organizan según la cantidad de cambios.

Qué se considera un cambio

Un cambio es concreto y diferenciable.

Se considera cambio a una modificación concreta y diferenciable sobre contenido, diseño, comportamiento o elemento existente del sitio.

La cantidad de cambios no se determina únicamente por la cantidad de elementos visuales afectados, sino por la lógica de la modificación.

Ejemplos
  • Cambiar un texto específico.
  • Reemplazar una imagen.
  • Modificar un enlace.
  • Cambiar un documento descargable.
  • Ajustar un botón.
  • Modificar una propiedad visual.
  • Reorganizar una sección existente.
  • Ajustar el comportamiento responsive de un componente.
  • Modificar una interacción ya desarrollada.

Una modificación global realizada mediante una única implementación técnica podrá contabilizarse como un único cambio, aunque afecte múltiples elementos. Cuando las modificaciones requieran tratamientos independientes, se contabilizarán por separado.

Cambios globales Un ajuste, un cambio.

Una modificación que pueda aplicarse globalmente mediante un único ajuste técnico podrá considerarse un solo cambio, aunque afecte múltiples elementos.

Ejemplo

Modificar un color definido globalmente y utilizado en diferentes partes del sitio podrá considerarse:

1 cambio

y no un cambio por cada elemento afectado.

De la misma forma, una modificación general sobre una regla CSS o comportamiento compartido podrá contabilizarse como un único cambio cuando técnicamente corresponda a una sola intervención.

Cambios individuales Cada elemento, su cambio.

Cuando los elementos requieran modificaciones independientes, podrán contabilizarse como cambios separados.

Ejemplo

Modificar individualmente el contenido y comportamiento de cinco componentes diferentes podrá equivaler a:

5 cambios

La cantidad definitiva siempre será determinada luego de analizar el requerimiento.

Metodología general de trabajo

Ocho pasos, sin sorpresas.

Este documento funciona como una guía general de precios y modalidad de trabajo.

La cantidad definitiva de cambios se determina después de recibir y analizar cada solicitud.

La metodología será la siguiente.

  1. 1

    Envío de requerimientos

    VALCA deberá enviar de manera clara y detallada las modificaciones que desea realizar.

    Siempre que corresponda deberá proporcionar:

    • textos definitivos;
    • imágenes;
    • enlaces;
    • documentos;
    • referencias visuales;
    • comportamiento esperado;
    • cualquier recurso necesario para implementar los cambios.

    Se recomienda enviar los requerimientos de forma agrupada.

  2. 2

    Modalidad utilizada

    La solicitud podrá realizarse mediante:

    Plan A — Mantenimiento mensual

    o

    Plan B — Actualización bajo demanda

  3. 3

    Evaluación

    Se analizarán los requerimientos recibidos y se informará:

    • cantidad de cambios identificados;
    • consumo mensual, en caso de Plan A;
    • valor total, en caso de Plan B;
    • cualquier requerimiento considerado nuevo desarrollo.
  4. 4

    Aprobación

    VALCA deberá aprobar el alcance informado antes de comenzar el trabajo.

  5. 5

    Pago

    Se realizará el pago o anticipo correspondiente según la modalidad contratada.

  6. 6

    Reserva de agenda

    Una vez acreditado el pago correspondiente, el trabajo será incorporado a la agenda.

  7. 7

    Ejecución

    Se implementarán los cambios aprobados.

  8. 8

    Verificación y publicación

    Una vez finalizado el trabajo se comprobará el correcto funcionamiento y se publicarán las modificaciones.

Para ambos planes

Condiciones comunes.

01Solicitudes urgentes

Se considera urgente una solicitud que requiera:

  • alterar la planificación existente;
  • reprogramar otros trabajos;
  • otorgar prioridad extraordinaria;
  • realizar modificaciones dentro de un plazo excepcionalmente corto.

Estas solicitudes podrán tener un adicional de hasta:

50%

sobre el valor correspondiente.

La posibilidad de aceptar una solicitud urgente estará siempre sujeta a disponibilidad.

02Correcciones incluidas

Las correcciones necesarias como consecuencia de un error de implementación respecto del requerimiento aprobado se encuentran incluidas sin costo.

Ejemplo

VALCA solicita reemplazar una imagen específica.

Por error se publica otra.

La corrección no consume un cambio adicional.

03Cambios posteriores de criterio

No se consideran correcciones los cambios posteriores sobre un requerimiento correctamente implementado.

Ejemplos:

  • enviar una nueva imagen;
  • modificar nuevamente un texto;
  • cambiar de opinión sobre un color;
  • reemplazar contenido previamente aprobado;
  • solicitar una nueva distribución.

Estos casos se contabilizarán como nuevos cambios.

04Modificaciones agregadas durante el trabajo

Si durante la ejecución VALCA solicita incorporar nuevos cambios que no formaban parte del requerimiento aprobado, estos serán agregados al conteo correspondiente.

En Plan A:

Se descontarán de los cambios disponibles del mes.

En Plan B:

Podrán modificar el valor correspondiente, según la cantidad total de cambios.

Siempre se informará previamente cuando una modificación adicional implique superar el alcance originalmente aprobado.

05Facturación

Todos los servicios serán facturados en Argentina mediante la emisión del comprobante fiscal correspondiente.

Los valores informados representan el importe final del servicio según la condición fiscal aplicable al prestador.

06Moneda

Todos los valores de la propuesta se encuentran expresados en:

Pesos argentinos (ARS)

07Actualización de valores

Los valores serán actualizados:

Trimestralmente

utilizando como referencia la variación acumulada del:

Índice de Precios al Consumidor (IPC) — Nivel General publicado por INDEC.

La fórmula utilizada será:

Nuevo valor = valor vigente × (1 + variación acumulada del IPC del período)

Se utilizará el último índice oficial disponible al momento de realizar la actualización.

08Valores sujetos a actualización

La actualización trimestral se aplicará a:

  • Plan A mensual;
  • valores del Plan B por cantidad de cambios (hasta 5, 10 y 15 cambios);
  • cambios adicionales;
  • valores base utilizados para nuevos trabajos.

La actualización no requiere renegociar nuevamente las condiciones generales del servicio.
